## 执行流程

### 1. 登录检查

调用 `check_login_status` 检查登录状态。

- 未登录 → 提示用户先用 `dianshu-login` 扫码登录
- 已登录 → 进入步骤 2

### 2. 确认查询条件

从用户输入中提取筛选条件：
- `orderType`（可选）— 订单类型：0-全部（默认），1-数据集，2-API
- `orderCode`（可选）— 按订单编号查询

### 3. 调用查询

调用 `list_orders`：
- `orderType`（number，可选）：0-全部(默认)，1-数据集，2-API
- `orderCode`（string，可选）：订单编号

### 4. 展示结果

将查询结果整理为列表展示，每条包含：
- 订单编号、订单名称
- 订单金额、价格
- 订单状态、支付状态
- 支付方式、创建时间

提示用户可以：
- 查看某笔订单详情
- 切换筛选条件重新查询

## 失败处理

| 场景 | 处理 |
|---|---|
| 未登录 | 引导用户先使用 `/dianshu-login` 登录 |
| 无订单结果 | 说明当前暂无订单 |
| 查询失败 | 提示用户稍后重试或检查网络 |
